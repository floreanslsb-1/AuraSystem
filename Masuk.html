    Kapan: sebelum barang dari distributor baru datang, atau saat distributor mengirim price list terbaru. Gunanya: HET produk baru terisi otomatis.
    1. Klik 📋 Salin prompt price list.
    2. Buka Claude / Gemini → tempel prompt → ganti baris VENDOR (nama persis seperti di Odoo) dan CATATAN (aturan khusus, mis. harga per lusin) → lampirkan foto/PDF katalog → kirim.
    3. Cek catatan AI (baris yang ragu) → salin isi tabel → tempel di bawah → Simpan. Produk yang sudah ada diperbarui, sisanya ditambahkan.
    Kapan: setelah nota berisi produk baru / brand baru selesai di-import ke Odoo. Gunanya: perubahan harga berikutnya bisa lewat file import, bukan diketik manual di pricelist.
    1. Odoo → POS → Produk → Daftar Harga → centang Harga Aura → ⚙ Ekspor.
    2. Centang "Saya ingin memperbarui data (kompatibel impor)". Kolom: ID Eksternal, Peraturan Daftar Harga / ID Eksternal, Peraturan Daftar Harga / Produk / ID Eksternal → Ekspor.
    3. Buka file hasil export → blok semua isi termasuk judul kolom → Copy → tempel di bawah → Sinkronkan.
